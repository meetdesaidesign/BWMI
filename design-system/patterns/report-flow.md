# Report flow

Photo first, then AI review, then submit.

1. Capture — large media stage, optional gallery, optional location.
2. Analyzing — inverse canvas (EX-002); layout dimensions do not depend on a 3D asset.
3. Review — editable fields, category chips, duplicate card.
4. Success — confirmation, then the report’s updates.

Sticky primary action stays inside the phone frame, not the desktop viewport.
Every AI field remains editable. Duplicate suggestion recommends backing the existing issue; “This is different” remains available.
