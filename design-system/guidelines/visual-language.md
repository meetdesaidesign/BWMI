# Visual language — Civic Signal

Pakka is a civic reporting tool used outdoors, often one-handed. The interface should feel calm, tactile and official without looking like a government portal template.

## Intent

- **Human:** a resident standing on a street, photographing a problem, then checking later whether it was actually fixed.
- **Job:** report quickly, understand status, confirm or contest a claimed repair.
- **Feel:** municipal wayfinding — infrastructure blue, reflective evidence yellow, repair green only after a resident confirms.

## Domain

Ward maps, public updates, evidence stamps, team ownership, support counts, confirmation checkpoints.

## Color world

Wet asphalt and monsoon gray, municipal sign blue, barrier yellow, cone orange, fresh repair paint green. Surfaces stay cool-neutral; color is reserved for status and action.

## Signature

The **evidence stamp** — reflective yellow on photographs and resident checkpoints. A repair is not visually “done” until that checkpoint is confirmed.

## Depth

Borders and tonal shifts for static grouping. Shadows only on floating layers (map chrome, sheets, FABs).

## Rejected defaults

- Compact 8–11px metadata → approved caption 12/16.
- Full-bleed blue app header on the map → floating elevated chrome.
- Text-only issue rows → media result cards.
- Dark cinematic UI → light civic canvas (Hindi + outdoor legibility).
