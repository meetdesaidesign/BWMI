# Placeholder guidelines

3D illustrations are content, not layout.

- Placeholder and final artwork share the same slot dimensions.
- Use transparent PNG/WebP; never bake a card background into the asset.
- Decorative assets: empty alt. Meaningful assets: concise alt.
- If an asset fails, show the fallback icon — never collapse the slot.
- Crop/safe-area lives in the manifest so replacement art stays consistent.
